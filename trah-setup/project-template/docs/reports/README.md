# Отчёты проверок

`ГГГГ-ММ-ДД-<слаг>.md`. Сюда пишут агенты, а не человек.

- `critical-reviewer` — разбор сделанной работы на дефекты: полный отчёт
  ложится сюда, наверх возвращается короткая выжимка.
- навык `security` — находки прохода по безопасности.

Почему файлом, а не сообщением: отчёт, прочитанный один раз в уведомлении,
через неделю не существует. Файл лежит рядом с планом, к которому относится, и
его можно перечитать, когда дефект всплывёт снова.

Отчёты не удаляются. Они дешёвые и датированные.
