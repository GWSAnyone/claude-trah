# Планы задач

По файлу на задачу, имя `ГГГГ-ММ-ДД-короткий-слаг.md`.

План — **рабочий журнал агента**, а не техзадание для человека. Он существует
потому, что сжатие контекста и смена сессии уносят всё, что не лежит на диске.
Поэтому в нём:

- **«Где я сейчас»** — обновляется на каждом закрытии шага, читается первым при
  возврате. Внутри: фаза, что не закончено, следующее действие одной конкретной
  фразой, что не закоммичено, открытые вопросы.
- **«Что пробовали и отвергли»** — с причиной отказа. Текущее состояние можно
  вывести из кода, отброшенный подход — ниоткуда.
- Ход работы галочками **в этом же файле**. Отдельный файл прогресса заводить
  не надо: два файла расходятся.

Подробнее — `.claude/rules/docs-layout.md`.

Указатель на активный план пишет хук чекпоинта:
`.claude/.checkpoint-<хост>-<8 знаков сессии>`. Имя составное не из
аккуратности: каталог может синхронизироваться между машинами, и несколько
сессий работают в одном дереве одновременно.
