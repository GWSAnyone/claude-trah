# /dedup — дубли кода

Инструмент — `~/.claude/dedup/` (ядро `dedup.py`, запуск `dedup.sh`, настройка
`dedup-setup.py`). Настройка — у проекта, `.claude/dedup.json` в его корне;
ищется вверх от текущего каталога. Нет настройки — **сначала SETUP.md** рядом:
настройка идёт вместе с владельцем.

Языки: Go (`back`), JS (`front`), CSS, HTML, Rust. Зависимости ставит `uv`
при первом запуске.

## 1. Кандидаты — `dedup.sh`

```bash
D=~/.claude/dedup
$D/dedup.sh .                          # весь проект (корень настройки): группы, сильнейшие сверху
$D/dedup.sh .:rust --judge 120         # + метки Haiku для первых 120 групп (~70 с)
$D/dedup.sh .:rust --judge 120 --only-dup  # в отчёт — только подтверждённые DUP
$D/dedup.sh A B --cross                # при layout subprojects: только дубли МЕЖДУ проектами
$D/dedup.sh A --ref                    # проект против общего кода из refs настройки
$D/dedup.sh --focus <файл> --json      # функции одного файла против проекта (так работает хук)
```

На Windows без bash — `uv run --with tree-sitter-language-pack --with
scikit-learn ~/.claude/dedup/dedup.py …` с теми же аргументами.

Выход — `/tmp/dedup-<цели>/` (или `--out`): `candidates.md` (у группы строка
«почему»: какой сигнал сработал и на чём), `candidates.json` (с id пар и меткой
судьи) и `catalog.json` (все функции — для прохода моделями).

Сигналы: **shape** — копия с переименованием (treepeat, имена обезличены);
**vocab** — одно дело разной структурой (общие вызовы, поля, ключи, строки, с
весами TF-IDF; сравниваются и крупные блоки `имя#N` внутри длинных функций);
**name** — одно имя в разных файлах. Не видит «одно дело, разные слова» и общий
кусок в три строки посреди больших функций — это фаза 3.

## 2. Отсев

Кандидат — не приговор. `--judge N` даёт группе метку DUP / IDIOM / NO от Haiku.
Бриф судьи — общий каркас `~/.claude/dedup/judge-brief.md` и вставка проекта
`.claude/dedup-brief.md` (что за код, примеры, нарочное сходство). Кэш — по
хэшу брифа и кода: новый бриф — новые метки.

**Судья ставит DUP группе, если одинаковы хотя бы два члена** — они в поле
`members`. Остальные члены группы — соседи по словарю. Сводить только
`members`, и только прочитав их тела целиком.

Точность (замеры 30.09.2026 на ботах, слепая разметка): инструмент один —
сильнейшие группы 92 %, весь список 68 %; с фильтром Haiku — 86 %. Метки —
фильтр, а не решение.

Принятое — идиома, дубль нарочно — в файл принятых пар (`accepted` настройки,
по умолчанию `.claude/dedup-accepted.txt`) с причиной: пара по id
(`файл::имя | файл::имя`) или `name:<имя>` для идиомы. Больше не всплывает ни
в отчёте, ни в хуке. Блоки `имя#N` по id не принимать: номер сдвигается с
правкой функции — такой источник убирать из обхода (`skip_dirs` настройки).

## 3. Одно дело, разные слова (по желанию)

`catalog.json` → раскладка по назначению агентом `model: haiku` (промпт
`categorize.md` рядом) → `~/.claude/dedup/dedup-split.py <папка>` → по агенту
на категорию (промпт `find-duplicates.md`). Метод — obra/superpowers-lab
`finding-duplicate-functions` (MIT). Дорого: запускать, когда фаза 1 вычищена.

## 4. Свести

1. Сначала копии, что УЖЕ разошлись в поведении (судья пишет drift в `why`),
   и всё, что трогает деньги, сохранение, протокол.
2. Одна копия-наследник, остальные зовут её. Дом — модуль ниже по графу
   зависимостей, которым уже пользуются оба, а не новый «utils».
3. Поведение, которого не было у одной из копий, — изменение: назвать его в
   отчёте владельцу.
4. Проверка — как у любой правки проекта: сборка, линтер, тесты. Коммит — по
   слову владельца.

## 5. Защёлка — чтобы долг не рос

Хук `~/.claude/hooks/dedup-latch.py` (PostToolUse: Write, Edit, MultiEdit,
правки Serena). По состоянию настройки:

- **не настроено** (`setup` или нет файла) — ничего не сканирует; один раз за
  сессию просит предложить владельцу настройку (SETUP.md) или выключение;
- **on** — каждая `every`-я правка кода: функции правленых файлов против
  проекта, только пары не из базовой линии, с меткой судьи; модели — только DUP;
- **off** — молчит.

Первая проверка строит базовую линию молча: старый долг — не новость. Линия
перестраивается сама при смене пропусков или общего кода. Сломанная защёлка
(нет uv, судья не отвечает) говорит об этом один раз за сессию;
`dedup-setup.py status` показывает последнюю ошибку. Выключить на сессию —
`DEDUP_LATCH=0`.

**Защёлка срабатывает посреди переноса.** Пятая правка может прийти, когда
общая функция уже написана, а старые копии ещё не удалены. Если второй член
пары правился в той же пачке, хук так и пишет: «возможно, недоделанный
перенос» — доведи его и не вноси пару в принятые.
