## Что такое «1.0»

Номера у комплекта сейчас нет: ни тегов, ни релизов на GitHub, `trah-setup/version.txt`
— это прицел Claude Code (`2.1.284`), а не версия комплекта. Предлагаемое:

- тег `v1.0.0` на коммите, где все шаги ниже зелёные или явно сняты владельцем;
- файл с версией комплекта, который печатают `./trah status` и `--version` копии
  (сейчас там «2.8.2 (tweakcc-fixed)» — это версия форка, а не наша);
- релиз на GitHub с заметками: что входит, на какой версии CC проверено, как ставить.

Тег, пуш и релиз — только по отдельному «да» владельца.

## Критерии готовности

Каждый шаг закрывается замером, а не впечатлением. Шаг зелёный, когда его
проверки прошли и записаны сюда с числами. Красный шаг — либо чиним, либо владелец
снимает его словами; молча не пропускается.

## Замеры

### M1, устройство модов (02.10, документация `code.claude.com/docs/en/plugins/mods` и `/reference`)

- Мод = плагин: `.claude-plugin/plugin.json`, `hooks/hooks.json` с `"modules": ["./register.js"]`
  (там же можно держать и обычные хуки под `hooks`), модуль ES с `register(on, options)`.
  Хук `($, e, next)`, как промежуточное ПО; `e` заморожен, менять — копией в `next`.
- Грузится: из маркетплейса (`claude plugin install имя@маркет`), на одну сессию
  `--plugin-dir`, или переменной `CLAUDE_CODE_PLUGIN_DIRS` (в т.ч. в `env` настроек —
  «для приложений, которым не передать флаг», то есть для VS Code). `/reload-plugins`.
- Где работают хуки: терминал, Desktop, **чат VS Code (хуки да, рисование нет)**, `-p`/SDK.
- Выключают: `--safe-mode`, `--bare`, `disableAllHooks` (вместе с нашими хуками настроек).
- Пределы: 10 с собственного времени хука на событие, `.catch` 1 с, `session.end` 1,5 с
  на всех. Упавший хук пропускает событие как есть (провал = штатное поведение, не поломка).
- События обычных хуков доступны модам как `classic.<Event>` (`e` — тот же stdin JSON).
- Новое, чего не было в 02.10-заметке: `$.session.compact` (операция сжатия —
  заказ сжатия без сокета и без `/compact`), `$.tool.register` и `$.command.register`
  (команда исполняется сразу, без хода модели, даже посреди хода), `$.prompt.submit`
