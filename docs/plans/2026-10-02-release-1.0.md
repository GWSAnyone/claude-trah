## Что такое «1.0»

Номера у комплекта сейчас нет: ни тегов, ни релизов на GitHub, `trah-setup/version.txt`
— это прицел Claude Code (`2.1.284`), а не версия комплекта. Предлагаемое:

- тег `v1.0.0` на коммите, где все шаги ниже зелёные или явно сняты владельцем;
- файл с версией комплекта, который печатают `./trah status` и `--version` копии
  (сейчас там «2.8.2 (tweakcc-fixed)» — это версия форка, а не наша);
- релиз на GitHub с заметками: что входит, на какой версии CC проверено, как ставить.

Тег, пуш и релиз — только по отдельному «да» владельца.

## Критерии готовности

Каждый шаг закрывается замером, а не впечатлением. Шаг зелёный, когда его
проверки прошли и записаны сюда с числами. Красный шаг — либо чиним, либо владелец
снимает его словами; молча не пропускается.
