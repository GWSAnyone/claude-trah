## Зачем обновлялись

- 2.1.270 чинит регрессию 2.1.269: read-only git в Bash через какое-то время
  начинал спрашивать разрешение.
- 2.1.271: `/resume` больше не теряет `[1m]`; фоновая команда не стартует второй
  копией после сжатия; tool search находит MCP-инструмент по голому имени.
- 2.1.273: `/login` и `/upgrade` больше не выбрасывают размышления и не рушат
  кэш промпта; подагенты не объявляются упавшими, если в последнем ответе нет
  usage. `permissions`: подоболочка больше не прячет опасный `rm` в bypass.
- VS Code: новый чат не перескакивает на прежний при обновлении списка сессий;
  настройка `claudeCode.attachOpenFile`.

## Что пробовали и отвергли

- Образец `(a+)+$` для проверки таймаута: модуль `regex` его оптимизирует и не
  зависает. Работает `(\w|\w\w)*$` на `"a"*60+"!"`.
- Откат переезда Serena на прицел: прицел может уже совпадать с целью. Откат
  идёт на коммит, который реально стоял.
- `git checkout -- .` для чистки кэш-клона запрещён гардом. Чистые исходники
  берутся через `git archive`, без checkout.

- `./trah --check | tail`: хвост показал один промах из трёх. Смотреть весь вывод.
- `grep -aoE '.{N}якорь.{N}'` по бинарнику на 200 МБ идёт минутами. Нужно
  `grep -aobF` со смещением и `dd`: секунды.
- WebFetch changelog'а пересказывает маленькой моделью и режет пункты. Брать
  сырой `CHANGELOG.md` через curl.
- Доверять отчёту `port.py` «перенесён». Два ханка из 36 легли не туда, см.
  `claude-code-vsc/tools/README.md`, «Склейка разнесённых правок».
