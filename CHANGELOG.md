# Журнал изменений

Записи — для агента, который обновляет установку, и для человека, который
решает, обновляться ли. В каждой версии: что изменилось в поведении, что
изменилось в устройстве и **как обновиться**.

---

## 1.0.2 — сжатие по заказу в VS Code

Цель та же — Claude Code **2.1.287**.

### Как обновиться (для агента)

1. `git pull` в каталоге репозитория.
2. `python3 claude-code-vsc/tools/build.py --install`, затем перезагрузить окно
   VS Code.

### Что изменилось

- **Самосжатие в VS Code снова работает.** С 1.0.0 заказ (`compact-order.py`)
  исполнял мод в конце хода, но в сессии VS Code CLI этот вызов отклоняет:
  для него это SDK-сессия. Теперь там заказ исполняет форк расширения — после
  хода шлёт `/compact`, как при ручном вводе. В терминале всё по-прежнему
  делает мод.

## 1.0.1 — расширение VS Code на 2.1.287

Цель та же — Claude Code **2.1.287**. Поправка к 1.0.0.

### Как обновиться (для агента)

1. `git pull` в каталоге репозитория.
2. Мод: `./trah build`. Пересобирает копию 2.1.287 и мод, сверяет доставку.
3. Расширение VS Code (если человек пользуется форком):
   `python3 claude-code-vsc/tools/build.py --install`, затем перезагрузить
   окно VS Code.
4. `./trah tests` — сорвалось 0.
5. Скажи человеку о снимке промпта (раздел ниже), если он продолжает старые
   разговоры в VS Code.

### Что изменилось

- **Форк расширения VS Code переехал с 2.1.284 на 2.1.287.** Все правки
  форка на месте: полосы расхода и агентов, ленты подагентов, заголовки Serena,
  возврат фокуса в поле ввода, фоновые задачи. Порядок переезда и итог проверок —
  раздел «Переезд 2.1.287» в `claude-code-vsc/tools/README.md`.
- **Кусок `sys-communication-style`** говорил про три блока ответа, а с 1.0.0
  их четыре. Исправлено. На Opus 5.5 и Sonnet 5.5 кусок не ложится: строк,
  которые он заменяет, в их промпте нет.

### Снимок промпта в VS Code

VS Code запускает сессию со снимком системного промпта: промпт записывается при
первом запросе разговора и потом отправляется как есть, даже если новый запуск
передаёт другой текст. Обновляется он только при сжатии. Поэтому продолженный
старый разговор живёт со старым форматом ответа и после перезапуска VS Code.
Новый разговор получает новый промпт сразу, старый — после первого сжатия.

## 1.0.0 — переезд на моды Claude Code и защёлка дублей

Цель — Claude Code **2.1.287**. Крупный релиз: поменялось устройство режима
`claude trah`, появился новый хук, сменилась форма ответа.

### Как обновиться (для агента)

Человек дал тебе ссылку на репозиторий снова — значит, комплект у него уже
стоит, и твоя задача обновить его, ничего чужого не потеряв.

1. Обнови клон: `git pull` в каталоге репозитория (или склонируй заново, если
   клона нет).
2. **Показ, без записи:** `./trah --check`. Прочитай «ДАЛЬШЕ РУКАМИ» и
   столкновения — правила те же, что при установке (CLAUDE.md в корне):
   чужой файл без «да» человека не трогается.
3. Установка комплекта: `./trah`. Ставит новые хуки, защёлку дублей, скилл
   `dedup`, обновлённую обёртку `claude`.
4. Переезд на 2.1.287: `./trah upgrade 2.1.287 --check`, затем без `--check`.
   Нужен сам Claude Code 2.1.287 на машине (`claude update`). Переезд
   собирает патченую копию и мод, сверяет доставку каждого куска и только
   потом переставляет ссылку; при сбое ссылка возвращается.
5. `./trah tests` — сорвалось 0.
6. **Скажи человеку перезапустить все сессии `claude trah`.** Старые сессии
   остаются на прежней сборке до перезапуска.
7. Защёлка дублей включена по умолчанию в состоянии «не настроено» — ничего не
   сканирует, пока человек не решит. Расскажи ему о ней (раздел ниже) и не
   настраивай ни одного проекта без его слова.

Откат: `ln -sfn <прежняя версия> ~/.local/share/claude/trah/current` и
`ln -sfn mod-<прежняя версия> ~/.local/share/claude/trah/mod` (если мод был).

### Устройство: моды вместо части патчей

С 2.1.287 у Claude Code есть официальные моды — модули хуков плагина
(`hooks/register.js`). Всё, что мод доносит до модели **в то же место**, что и
патч бинарника, переехало в мод `trah` (`~/.local/share/claude/trah/mod-<версия>`,
обёртка подключает его `--plugin-dir`):

- описания инструментов, системный промпт главной сессии, напоминания CLI,
  подпись коммитов и PR — 18 кусков;
- **сжатие по заказу** (`compact-order.py`) — мод исполняет заказ в конце хода,
  щель в обработчике сокета больше не нужна;
- **файл после сжатия** возвращается ссылкой, а не содержимым — и после
  `--resume` тоже;
- текст режимов auto/bypass про Bash — **находка 1.0**: на 2.1.28x сервер
  выбирает одну из двух редакций текста, патч правил только старую, и в
  сессии приезжал штатный приказ «читай через cat, правь через sed». Мод
  правит обе.

Патчем бинарника (tweakcc) остаётся то, что мод доставил бы только в ДРУГОЕ
место, то есть с потерей качества:

- бриф подагента (мод положил бы его в задание, а не в системный промпт);
- встроенные агенты general-purpose и Explore (мод не подменяет встроенных);
- задание сводки при сжатии (мод только дописывает «Additional Instructions»);
- промпт оценщика `/goal` (до него мод не доходит).

**Зависимость от флага Anthropic.** Моды грузятся, пока сервер держит включённым
флаг раскатки `tengu_plugin_hooks_modules`. Выключен — мод не загружается,
куски маршрута mod работают по-штатному, а обёртка при запуске пишет «Anthropic
выключила моды». Это не поломка установки; обходить выключатель комплект не
будет.

### Поведение

- **Защёлка дублей** — новый хук, см. ниже.
- **Форма ответа**: четыре блока — Итог, Вопросы, **Что дальше**, Что
  изменилось. «Что дальше» — единственное место про следующий шаг: жду ответа /
  план готов, «пиши погнали» / продолжаю сам (только при заказанном сжатии).
  Коды реестров и планов в ответе — с файлом и строкой определения.
- **Режим разрешений**: `claude trah` стартует в bypass и тогда, когда функция
  fish подставляет `--allow-dangerously-skip-permissions`, а в настройках стоит
  `defaultMode: auto` (раньше в этом сочетании сессия поднималась в auto).
- **Одна дверь `./trah`**: `upgrade ВЕРСИЯ [--check]`, `build`, `brief`;
  автопереезда на новую версию нет — новая версия на машине выводится строкой в
  «ДАЛЬШЕ РУКАМИ»; сборка всегда заканчивается сверкой доставки.

### Защёлка дублей (новое)

Хук `~/.claude/hooks/dedup-latch.py` (PostToolUse на правки) и инструмент
`~/.claude/dedup/`. Каждая N-я правка кода (Go, JS, CSS, HTML, Rust) ищет в
проекте уже существующие функции с тем же делом; найденное судит Haiku, модели
показываются только дубли. Старый долг проекта не всплывает: первая проверка
строит базовую линию.

- Настройка — у проекта, `.claude/dedup.json`. По умолчанию её нет, и это
  состояние «не настроено»: на первой правке кода хук один раз за сессию просит
  модель предложить человеку **настроить** (по гайду
  `~/.claude/skills/dedup/SETUP.md`, вместе с ним) или **выключить**
  (`dedup-setup.py off`).
- Нужен `uv` (https://docs.astral.sh/uv/); первый запуск качает зависимости из
  PyPI. Судья — голый бинарь Claude Code с Haiku, токены подписки.
- Сломанная защёлка (нет uv, судья не отвечает) говорит об этом один раз за
  сессию; `dedup-setup.py status` — последняя ошибка.
- Отчёт по всему проекту и сведение найденного — скилл `dedup`.

### Windows

Комплект писался и проверялся на Linux. Защёлка сделана переносимой (замки
через `msvcrt`, хук зовёт `uv run … dedup.py` без bash, пути в id пар через
`/`), но на живой Windows **не проверялась**. Что смотреть в первую очередь —
раздел «Windows» в `trah-setup/skills/dedup/SETUP.md`. Обёртка `claude` и
патч бинарника под Windows по-прежнему не поддерживаются.
