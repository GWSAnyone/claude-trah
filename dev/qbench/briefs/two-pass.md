# Second pass

The first draft is never the deliverable. After the tests pass, reread every line you added as the maintainer of this repository would, against the sibling modules of the same kind, and rewrite whatever a senior maintainer would ask to change: a name that is not from this codebase's vocabulary, an error type the package does not use, a log line shaped differently from the neighbours, an abstraction the task did not need, a test that does not use the shared fixtures. Then run the checks again and finish.
