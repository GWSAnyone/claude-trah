# Мастерская

Инструменты, которыми режим изучают, а не которыми он работает. На машину они
не ставятся: `install-kit.py` о них не знает, в `~/.claude` они не попадают, и
ни один хук их не зовёт. Ломаться они при этом умеют так же тихо, как всё
остальное, поэтому их наборы проверок идут в общем прогоне `./trah tests`.

Граница простая: **в `trah-setup/` лежит то, без чего режим не соберётся или не
поставится; здесь — то, чем меряют и разглядывают.**

| файл | зачем |
|---|---|
| `session-metrics.py` | восемь величин по стенограммам: ширина пачки, состав вызовов, ошибки, длина ответа. С разбивкой по уровню усилия, версии и ветке |
| `batch-width.py` | ширина пачки вторым, независимым счётом — им перекрёстно сверяется метрика M1 из `session-metrics.py`. Второй инструмент здесь не дубль, а способ поймать общую ошибку в одном из них |
| `harness-usage.py` | перепись оснастки: что из Serena, подагентов, навыков и MCP реально звалось |
| `harness-rent.py` | сколько знаков системного промпта арендует каждая карточка навыка и агента |
| `capability-bait.py` | калибровка приманками: десять задач через настоящий `claude`, что сработало на самом деле |
| `catalogue.py` | опись кусков штатного промпта по корпусу tweakcc: что уже занято, что свободно |
| `anchors.py` | счёт вхождений строки в байтах бинарника с окрестностью каждого — этим ищут новую форму разошедшегося якоря |
| `relay.py` | посредник с настоящими токенами: единственный, кому видны промпты подагентов |
| `check-subagent.py` | по улову посредника — дошла ли дисциплина до системного промпта подагента |
| `check-brief-delivery.py` | доехали ли ОДНОВРЕМЕННО бриф и правки бинарника, настоящим запуском обёртки |
| `check-workspace-sync.py` | разошлось ли содержимое файлов комплекта с тем, что стоит на машине |
| `compact-probe.py` | длина сводки сжатия и чем возвращаются прочитанные файлы после него |
| `qbench/` | стенд замера качества кода: парные прогоны `claude -p` и судья вкуса; свой `README.md` |

## Чего здесь больше нет

Удалено 07.09.2026 из `trah-setup/bin/` с разрешения владельца — всё перекрыто
тем, что осталось, и держать вторую редакцию значило бы сверять их между собой:

- `count-bullet.py` — тот же счёт вхождений, что `anchors.py`, только по одной
  зашитой фразе;
- `check-trah.py` — доставку правок проверяет `trah.py verify`, и он же
  поддерживается;
- `bash-matrix.sh`, `bash-variant.py`, `bash-diff.py` — одноразовый опыт с
  описанием `Bash` в четырёх режимах прав; в скрипте зашит путь на версию
  2.1.239, которой на машине давно нет.

Удалено 02.10.2026 при подготовке 1.0, по слову владельца «реши, чтобы всё
чётко было»:

- `swap-remind-hook.py` — разовая перестановка 07.09 апстримового хука Serena на
  прокладку прямо в `settings.json`. Прокладка давно стоит модулем диспетчера
  (`hooks/modules.json`), и скрипт поставил бы её вторым, лишним хуком.

`qbench/` переехал сюда из корня тогда же: это стенд замера, на машину он не
ставится.
