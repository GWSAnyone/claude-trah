# `claude trah` — режим запуска Claude Code

Комплект, который превращает штатный Claude Code в **свою сборку**: бинарник с
двадцатью одним вшитым куском промпта (28 правок), свой бриф в системном
промпте, четырнадцать хуков на девяти событиях, три подагента, пять навыков и
четыре MCP-сервера.

Запускается словом:

```bash
claude trah
```

Всё остальное — то же самое `claude`. Обёртка ловит это слово, подставляет
патченую копию бинарника, бриф, конфиг Serena и флаги — и уходит с дороги.

---

## Прочти это раньше остального

**Комплект правит копию бинарника Claude Code.** Не оригинал: оригинал остаётся
нетронутым, копия лежит рядом, и сумма оригинала сверяется до и после каждой
сборки. Но это всё равно изменение программы, которую вы не писали.

- К Anthropic отношения не имеет и ими не поддерживается.
- Якоря правок привязаны к **конкретной версии**. Вышла новая — часть якорей
  расходится, и это штатно (см. «Переезд» в [MECHANICS.md](MECHANICS.md)).
- Патчер — сторонний форк, `adhoc-patch` в нём запускается **без песочницы**.
  Скрипт правок исполняется с правами вашего пользователя.
- Режим `trah` добавляет `--dangerously-skip-permissions`. Это осознанный
  выбор владельца, а не недосмотр: без него `bypassPermissions` на ходу не
  включить. Хотите иначе — правьте обёртку, место названо в MECHANICS.

Если это неприемлемо — ставьте только хуки, агентов и навыки, а сборку
бинарника пропустите. Комплект от этого не разваливается: слой правок промпта
и слой хуков независимы.

---

## Из чего он состоит

Три слоя, каждый работает без остальных.

**1. Правки бинарника.** Куски текста, вшитые прямо в системный промпт и в
описания инструментов Claude Code. Ими чинится то, что снаружи не настраивается
ничем: скрытый запрет звать подагентов, указание авторежима править файлы через
`sed`, отсутствие дисциплины символьного слоя в описаниях `Read` и `Bash`.

**2. Бриф.** Собранный из кусков текст, который обёртка подаёт флагом
`--append-system-prompt-file`. Он попадает в **кешируемую** часть запроса, а не
пересылается прочитанным на каждом ходу, как `CLAUDE.md`. Замер переноса
20.08.2026: −5 124 и −6 762 эквивалента с сессии при неизменном содержимом.

**3. Хуки.** Четырнадцать перехватчиков на девяти событиях: гарды разрушительных
команд и разрешения на коммит, разбор файла после каждой правки, счёт ширины
пачки вызовов, чекпоинт вокруг сжатия контекста, самосжатие по заказу.

## Что он даёт — по-крупному

**Делегирование, которое иначе запрещено.** В промпте Opus 5 лежит строка
`Do not call the AgentTool unless the user requested it` (раздел `heron_brook`).
Она не настраивается ничем: ни ключом, ни флагом, ни переменной. Кусок
`sys-delegation-calibrated` меняет её на выверенную формулировку Anthropic.
Опыт с управлением — одна и та же сборка, запрет возвращается припиской: **0 и
0 подагентов с запретом против 4 и 4 без него** на одной задаче.

**Разбор каждой правки.** После `Write`/`Edit` хук разбирает файл: python, JSON,
YAML, TOML внутри процесса; `.go`, `.js`, `.sh` — внешними разборщиками. Только
разбор, никакого стиля: ложное срабатывание в хуке дороже пропущенной ошибки,
потому что приходит на КАЖДУЮ правку и его перестают читать.

**Счёт самого себя.** `PostToolBatch` пишет ширину каждой пачки вызовов живьём.
`session-metrics.py` считает девять величин по стенограммам с разбивкой по
уровню усилия и по датам. Отправная точка на 170 стенограммах записана — есть с
чем сравнивать через месяц.

**Самосжатие.** В штатном CLI `/compact` исполняется только с клавиатуры: любой
машинный путь до очереди ставит `skipSlashCommands`. Правка `sys-compact-on-order`
открывает одну щель — кадр `/compact` от СВОЕГО процесса (родство проверяет
ядро) исполняется как команда. Дальше это петля: хук считает накопленное чтение
из кеша, шлёт сессии напоминание, сессия пишет чекпоинт и заказывает сжатие,
после сжатия её возвращают к работе. Без единого нажатия.

**Гард коммита, который не верит на слово.** Маркер `OWNER_OK=1` в команде
показывает намерение, но ничего не доказывает — его пишет тот же, кого он
ограничивает. Вторым условием гард читает последнее сообщение человека в
стенограмме и ищет там согласие.

## Как ставить и обновлять — одна дверь

```bash
./trah              # поставить или обновить всё, что нужно этой машине
./trah --check      # ничего не записать, показать что изменилось бы
./trah status       # что стоит: версия, сборка, комплект, обёртка
./trah tests        # все наборы проверок
```

Отдельной команды «установить» нет намеренно: шаги идемпотентны, и первая
установка отличается от обновления только тем, что всё делается впервые.
Порядок внутри — комплект, сборка, обёртка — и он не случаен: сборка читает
куски из комплекта, а хук, ставящий обёртку, читает памятку
`~/.claude/trah-kit-path`, которую пишет установка комплекта.

Обновление Claude Code требует переезда: якоря правок привязаны к конкретной
версии. `./trah` видит новую версию сам и идёт по дороге `upgrade` — сверка
якорей, сборка, проверка доставки, все наборы проверок, и только последним
переписывается прицел `trah-setup/version.txt`. Сорвался любой шаг — переезда
не было, прежняя сборка продолжает работать.

## Источник истины

Комплект живёт и правится **здесь**. До 07.09.2026 он жил приложением к
соседнему рабочему репозиторию, а сюда переносился скриптом; тот репозиторий
ушёл в архив, и вместе с ним — скрипт переноса, хуки службы и Go-сборщик брифа.
Комплект от этого не потерял ничего: бриф режима собирается своим питоновским
сборщиком из `trah-setup/fragments`.

## Язык

Комплект русскоязычный насквозь: бриф, комментарии в коде, сообщения хуков,
эта документация. Часть кусков промпта — на английском, потому что они уезжают
в английский системный промпт и должны читаться с ним заодно.
