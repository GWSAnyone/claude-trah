# `claude trah` — режим запуска Claude Code

Комплект, который превращает штатный Claude Code в **свою сборку**: мод `trah` на
официальных модах Claude Code (19 кусков промпта, описаний инструментов и
напоминаний), патченый бинарник для того, что мод не достаёт (6 кусков, 10
правок), свой бриф в системном промпте, свой бриф для подагентов, хуки на десяти
событиях (19 вызовов), защёлку дублей кода, пять подагентов, шесть навыков и
четыре MCP-сервера. Цель — Claude Code 2.1.287.

Запускается словом:

```bash
claude trah
```

Всё остальное — то же самое `claude`. Обёртка ловит это слово, подставляет
патченую копию бинарника, мод, бриф, конфиг Serena и флаги — и уходит с дороги.

---

## Хочу это у себя

Скажите своему Claude Code ровно это:

```
Склонируй https://github.com/GWSAnyone/claude-trah и настрой мне окружение по
нему. Начни с CLAUDE.md в корне репозитория.
```

**Уже стоит и хотите обновиться?** Дайте агенту ту же ссылку: что изменилось
и как обновиться, записано в [CHANGELOG.md](CHANGELOG.md) — агент начинает с
него.

Дальше он справится сам. Файл [CLAUDE.md](CLAUDE.md) в корне загружается в его
сессию автоматически и отправляет его в [SETUP-AGENT.md](SETUP-AGENT.md), где
записан порядок работы.

Порядок этот такой: **сначала он осмотрит то, что у вас уже есть, потом покажет
план по пунктам, и только после вашего одобрения что-то поставит.** Комплект не
заменяет ваше рабочее место. Ваши навыки, агенты и хуки остаются: наши встают
рядом, а там, где имена или назначение совпали, агент обязан спросить вас, а не
решить за вас.

Посмотреть, что он найдёт, можно и самому — опись ничего не пишет на диск:

```bash
./trah inventory
```

## Прочти это раньше остального

**Комплект правит копию бинарника Claude Code.** Не оригинал: оригинал остаётся
нетронутым, копия лежит рядом, и сумма оригинала сверяется до и после каждой
сборки. Но это всё равно изменение программы, которую вы не писали.

- К Anthropic отношения не имеет и ими не поддерживается.
- Якоря правок привязаны к **конкретной версии**. Вышла новая — часть якорей
  расходится, и это штатно (см. «Переезд» в [MECHANICS.md](MECHANICS.md)).
- Патчер — сторонний форк, `adhoc-patch` в нём запускается **без песочницы**.
  Скрипт правок исполняется с правами вашего пользователя.
- Режим `trah` добавляет `--dangerously-skip-permissions`. Это осознанный
  выбор владельца, а не недосмотр: без него `bypassPermissions` на ходу не
  включить. Хотите иначе — правьте обёртку, место названо в MECHANICS.

Если это неприемлемо — ставьте только хуки, агентов и навыки, а сборку
бинарника пропустите. Комплект от этого не разваливается: слой правок промпта
и слой хуков независимы.

## Из чего он состоит

Четыре слоя, каждый работает без остальных.

**1. Мод `trah`.** С 2.1.287 у Claude Code есть официальные моды — модули хуков
плагина. Всё, что мод доносит до модели в то же место, что и патч, живёт в моде:
системный промпт главной сессии, описания инструментов, напоминания CLI, подпись
коммитов, сжатие по заказу. Ими чинится то, что снаружи не настраивается ничем:
скрытый запрет звать подагентов, указание авторежима править файлы через `sed`,
отсутствие дисциплины символьного слоя в описаниях `Read` и `Bash`. Моды грузятся,
пока Anthropic держит включённым флаг раскатки; выключен — обёртка предупредит.

**1б. Правки бинарника.** Только то, что мод доставил бы в другое место, то есть
хуже: бриф подагента в его системный промпт, встроенные агенты, задание сводки
при сжатии, промпт оценщика `/goal`.

**2. Бриф.** Собранный из кусков текст, который обёртка подаёт флагом
`--append-system-prompt-file`. Он попадает в **кешируемую** часть запроса, а не
пересылается прочитанным на каждом ходу, как `CLAUDE.md`. Замер переноса
20.08.2026: −5 124 и −6 762 эквивалента с сессии при неизменном содержимом.

**3. Хуки.** Перехватчики на десяти событиях: гарды разрушительных команд и
разрешения на коммит, разбор файла после каждой правки, защёлка дублей кода, счёт
ширины пачки вызовов, чекпоинт вокруг сжатия контекста, самосжатие по заказу.

## Что он даёт — по-крупному

**Делегирование, которое иначе запрещено.** В промпте Opus 5 лежит строка
`Do not call the AgentTool unless the user requested it` (раздел `heron_brook`).
Она не настраивается ничем: ни ключом, ни флагом, ни переменной. Кусок
`sys-delegation-calibrated` меняет её на выверенную формулировку Anthropic.
Опыт с управлением — одна и та же сборка, запрет возвращается припиской: **0 и
0 подагентов с запретом против 4 и 4 без него** на одной задаче.

**Разбор каждой правки.** После `Write`/`Edit` хук разбирает файл: python, JSON,
YAML, TOML внутри процесса; `.go`, `.js`, `.sh` — внешними разборщиками. Только
разбор, никакого стиля: ложное срабатывание в хуке дороже пропущенной ошибки,
потому что приходит на КАЖДУЮ правку и его перестают читать.

**Счёт самого себя.** `PostToolBatch` пишет ширину каждой пачки вызовов живьём.
`session-metrics.py` считает девять величин по стенограммам с разбивкой по
уровню усилия и по датам. Отправная точка на 170 стенограммах записана — есть с
чем сравнивать через месяц.

**Самосжатие.** В штатном CLI `/compact` исполняется только с клавиатуры: любой
машинный путь до очереди ставит `skipSlashCommands`. Мод открывает одну дверь —
заказ сжатия, положенный своей сессией, исполняется в конце хода тем же путём,
что `/compact`. Дальше это петля: хук считает накопленное чтение
из кеша, шлёт сессии напоминание, сессия пишет чекпоинт и заказывает сжатие,
после сжатия её возвращают к работе. Без единого нажатия.

**Гард коммита, который не верит на слово.** Маркер `OWNER_OK=1` в команде
показывает намерение, но ничего не доказывает — его пишет тот же, кого он
ограничивает. Вторым условием гард читает последнее сообщение человека в
стенограмме и ищет там согласие.

**Защёлка дублей.** Каждая пятая правка кода (Go, JS, CSS, HTML, Rust) сверяется с
проектом: не написала ли она заново функцию, которая уже есть. Кандидатов судит
Haiku, модели показываются только дубли, старый долг проекта молчит. В новом
проекте защёлка ничего не сканирует, а один раз предлагает настроить её вместе с
человеком (`~/.claude/skills/dedup/SETUP.md`) или выключить.

## Что настраивается без правки файлов

| переменная | что делает | умолчание |
|---|---|---|
| `TRAH_COMPACT_FIRST_M` | первая ступень напоминания о сжатии, в миллионах чтения из кеша | `30` |
| `TRAH_COMPACT_STEP_M` | шаг следующих ступеней | `30` |
| `NUDGE_SERENA_ROOTS` | какие каталоги считать своими рабочими деревьями | пусто |
| `NUDGE_COMPACT=off` | выключить напоминания о сжатии | включено |

Про пороги стоит знать, что счёт идёт по **чтению из кеша**, а не по размеру
контекста: это контекст, умноженный на число ходов, прожитых на нём. Прикидка,
по которой выбраны умолчания: 15 млн чтения — примерно 20 тысяч контекста,
30 млн — примерно 30 тысяч. Прикидка, а не замер: соотношение зависит от длины
ходов.

## Как ставить и обновлять — одна дверь

```bash
./trah              # поставить или обновить всё, что нужно этой машине
./trah --check      # ничего не записать, показать что изменилось бы
./trah inventory    # опись: что у вас уже есть и с чем комплект столкнётся
./trah status       # что стоит: версия, сборка, комплект, обёртка
./trah tests        # все наборы проверок
./trah project ПУТЬ # проектный уровень: скелет брифа, правил и docs/
```

Первые команды — **глобальный уровень**, `~/.claude`: одна установка на машину.
`./trah project` — **проектный**: свой у каждого рабочего каталога, в его git.
Разделение объяснено в [WORKSPACE.md](WORKSPACE.md), и оно не косметическое:
пять частей комплекта рассчитывают на `docs/plans/` и `docs/reports/` в
рабочем каталоге, а глобальная установка их не заводит и не может.

Отдельной команды «установить» нет намеренно: шаги идемпотентны, и первая
установка отличается от обновления только тем, что всё делается впервые.
Порядок внутри — комплект, сборка, обёртка — и он не случаен: сборка читает
куски из комплекта, а хук, ставящий обёртку, читает памятку
`~/.claude/trah-kit-path`, которую пишет установка комплекта.

Обновление Claude Code требует переезда: якоря правок привязаны к конкретной
версии. `./trah` видит новую версию и пишет о ней в «ДАЛЬШЕ РУКАМИ», но сам не
переезжает: переезд — `./trah upgrade <версия> --check`, затем без `--check`.
Сверка якорей и мода, сборка, проверка доставки, все наборы проверок, и только
последним переписывается прицел `trah-setup/version.txt`. Сорвался любой шаг — переезда
не было, прежняя сборка продолжает работать.

## Источник истины

Комплект живёт и правится **здесь**. До 07.09.2026 он жил приложением к
соседнему рабочему репозиторию, а сюда переносился скриптом; тот репозиторий
ушёл в архив, и вместе с ним — скрипт переноса, хуки службы и Go-сборщик брифа.
Комплект от этого не потерял ничего: бриф режима собирается своим питоновским
сборщиком из `trah-setup/fragments`.

## Язык

Комплект русскоязычный насквозь: бриф, комментарии в коде, сообщения хуков,
эта документация. Часть кусков промпта — на английском, потому что они уезжают
в английский системный промпт и должны читаться с ним заодно.
